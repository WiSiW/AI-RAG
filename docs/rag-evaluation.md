# RAG 评估建议

首版建议维护 30–50 条真实业务问题，覆盖：

- 单文档事实题
- 跨章节归纳题
- 跨文档比较题
- 表格/列表/代码块问题
- 无答案问题
- 多轮指代与追问
- 容易产生过时信息或冲突信息的问题

## 核心指标

| 指标 | 目标 |
| --- | --- |
| Recall@5 | 正确分块出现在前 5 的比例 |
| MRR | 正确分块排序质量 |
| Citation Precision | 引用来源确实支持陈述的比例 |
| Answer Faithfulness | 回答只包含参考资料事实的比例 |
| Abstention Accuracy | 无答案时正确拒答比例 |
| p95 First Token Latency | 首 token 延迟 |
| p95 Full Answer Latency | 完整回答延迟 |
| Ingestion Success Rate | 文档入库成功率 |

## 调参顺序

1. 先确认解析文本质量与分块边界。
2. 再比较 BM25、向量单路与混合检索。
3. 使用固定候选集调整 RRF 参数。
4. 评估 Rerank 分数分布，不要直接假定 `0.3` 阈值适用于所有模型。
5. 最后调整 Prompt、Top-K 与生成模型参数。

## 建议记录字段

- 问题
- 所属知识库
- 标准答案
- 必须命中的文档与章节
- 实际召回分块
- 回答
- 引用
- 是否拒答
- 延迟
- 人工评分
